# HisabKhata brand

## The mark

Two ledger columns (a shorter opening balance and a taller closing balance) joined by a rising emerald bar. Read together they form an **H**, a growth line and a page of a khata, sitting on a soft-blue ruled line. It is built from rectangles on a 64-unit grid so it stays crisp at 16 px.

| File                        | Use                                                                |
| --------------------------- | ------------------------------------------------------------------ |
| `hisabkhata-logo-light.svg` | Icon + wordmark on white or light grey                             |
| `hisabkhata-logo-dark.svg`  | Icon + wordmark on navy or dark surfaces                           |
| `hisabkhata-icon.svg`       | App icon, avatars, sidebar (navy tile)                             |
| `hisabkhata-mark-mono.svg`  | Single colour, inherits `currentColor` (stamps, watermarks, print) |
| `favicon.svg`               | 32-unit simplified mark for browser tabs                           |

The wordmark sets "Hisab" in bold navy and "Khata" in medium emerald. The SVG wordmarks reference Inter / system UI fonts; convert text to outlines in a vector editor before using them in print.

Keep clear space equal to the height of the emerald bar around the mark. Do not recolour the tile, add gradients, shadows or outlines, or rotate the bar.

## Colour

| Token       | Hex                               | Role                                          |
| ----------- | --------------------------------- | --------------------------------------------- |
| Navy        | `#0F1E3D`                         | Primary brand, sidebar, primary buttons, text |
| Emerald     | `#059669` (`#10B981` in the mark) | Money in, positive figures, success           |
| Soft blue   | `#7FA7E6`                         | Ledger rules, charts, focus rings             |
| Paper       | `#F6F8FB`                         | App background                                |
| Rule        | `#E3E8EF`                         | Borders and table lines                       |
| Red         | `#B91C1C`                         | Dues, negative figures, destructive actions   |
| Amber       | `#B45309`                         | Warnings, low stock                           |
| Dark canvas | `#0B1526` / `#111D33`             | Dark mode background / surface                |

Colour carries meaning; it is never decorative.

## Type

IBM Plex Sans (400/500/600) with tabular figures for every amount; Hind Siliguri for Bangla text. In PDFs: Inter for Latin and Noto Sans Bengali for Bangla and the taka sign (all SIL Open Font License).
